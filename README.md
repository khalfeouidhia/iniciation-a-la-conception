# Initiation à la conception — 3D Interactif

Application web 3D interactive pour le cours **Initiation à la conception** (Génie Logiciel, Cycle de vie documentaire) — ISET Kélibia.

## Fonctionnalités
- Visualisation 3D interactive (Three.js) des 8 chapitres et concepts clés (CQFD, Principes, Acteurs, Cycle de vie, Modèle en V / Cascade, Spirale, etc.).
- Fiches de révision et fiches détaillées par nœud.
- Mode lecture automatique et navigation intuitive.

## Déploiement
Le projet est déployé automatiquement via GitHub Pages sur :
**https://khalfeouidhia.github.io/iniciation-a-la-conception/**
